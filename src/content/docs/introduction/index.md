## What is Tales of Pirates?

Tales of Pirates (TOP) is a massively multiplayer online role-playing game (MMORPG) that was released in 2006. The game features a vibrant world filled with pirates, treasure, and adventure. Players can explore the world, complete quests, and engage in player-versus-player combat.

While the game was officially shut down in 2013, the community has continued to thrive with private servers and modding tools, allowing players to create their own content and experiences. 

Some of the most popular private servers include:

- **Pirate King Online** (PKO): A private server that aims to recreate the original game experience with new features and content.
- **TOP Online - Vanilla HD**: A private server that focuses on an authentic TOP 1 experience with some tweaks / mods applied to the game by default. It's focused on player-versus-player combat and competitive gameplay.
- **Pirates Online** (PO): A private server that has a focus on the new player experience, with a friendly community and helpful guides to help new players get started. It also has many aspects of its gameplay revamped to be more modern and accessible to new players.

## What is modding?

Modding is the process of creating or modifying content for a game. This can include creating new items, quests, characters, or even entire game worlds. Modding allows players to customize their gaming experience and create unique content that can be shared with others.

## Why mod?

ToP was created a long time ago, and while it was a great game for its time, it has some limitations. Modding allows players to:
- **Create new content**: Modding allows players to create new items, quests, and characters that can be added to the game. This can help keep the game fresh and exciting for players.
- **Fix bugs**: Modding can also be used to fix bugs and glitches in the game. This can help improve the overall experience for players and make the game more enjoyable.
- **Update the UI**: The game's user interface (UI) can be updated and improved through modding. This can help make the game more user-friendly and accessible to new players.
