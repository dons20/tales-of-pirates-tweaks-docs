Getting started with modding Tales of Pirates can be complicated, but this guide will help you get started, and help you to understand the basics up to even more advanced topics.

# Folder Structure

The folder structure of the game is important to understand when modding. This allows you to know where to find the files you need to modify, and understand how existing mods / tweaks affect the game.

Each private server tends to have slightly different folder structures, but they are all based on the same principles. The following is a general overview of the folder structure of Pirate King Online (click to expand):
