Getting started with modding Tales of Pirates can be complicated, but this guide will help you get started, and help you to understand the basics up to even more advanced topics.

## Folder Structure

The folder structure of the game is important to understand when modding. This allows you to know where to find the files you need to modify, and understand how existing mods / tweaks affect the game.

Each private server tends to have slightly different folder structures, but they are all based on the same principles. The following is a general overview of the folder structure of Pirate King Online (click to expand):

## Notable Folders

- **`animation`**: Contains the animation files for the game. This includes character animations, NPC animations, and more.
- **`cursor`**: Contains the cursor files for the game. This includes the cursor images and animations.
- **`effect`**: Contains the special effects files for the game. This includes particle effects, lighting effects, and more.
- **`font`**: Contains the font files for the game. This includes the font images and animations.
- **`model`**: Contains the 3D model files for the game. This includes character models, NPC models, and more.
- **`scripts`**: Contains the scripts for the game. This includes the Lua scripts, table files, and text files that control the game logic.
- **`texture`**: Contains the texture files for the game. This includes the textures for the 3D models, UI elements, and more.
- **`tweaks`**: Contains the tweaks for the game. This folder is not always present, as it is completely dependent on the server.
