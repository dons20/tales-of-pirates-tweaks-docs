## TOP Online - Vanilla HD

### Restore animations

<Steps>
1. Go into your `/scripts/txt` folder and backup `CharacterAction.tx`. This will allow you to revert any unwanted changes easily.
2. Download the <a href="/resources/CharacterAction.tx" download="CharacterAction.tx">modified `CharacterAction.tx` file</a>. Last 
3. Take the downloaded file, and replace the file in that same directory.
4. Run the game.
</Steps>
